## 第4课快速估算：三种方法总结（2026-11-12）

讲义中的三种方法总结已写入 `data-topic-course-04-estimation`：`methodComparison` 是方法对比表，采用“方法 / 适用范围 / 优点 / 缺点 / 注意事项与修正”五列；`contentSections` 新增第三个平行方法“放缩法”，原“化除为乘”与“份数思想”的内容、公式、两张速查表及修正方法保持不变。

- 化除为乘：变化率绝对值≤10%；快且准；正减负增（按绝对值），提前修正以凑整为主，方向正确时不必过分精确。
- 份数思想：增速≈1/n；快但精准计算较复杂；增量与增长率近似同比，提前修正类似乘法放缩，方向正确时不必过分精确。
- 放缩法：增速不适合前两种时使用；精准但不够快；放缩幅度不要太大，凑整为主，分子较整时可在结果上修正。

对比表属于章节总览，不取代三个方法各自的知识内容，不把讲义总结变成同级流水账。

## 份数法修正第三种方法：事前修正（2026-11-12）

在 `data-topic-course-04-estimation → 份数思想 → 份数法修正` 下，与方法一、方法二并列新增「方法三｜事前修正」。

- 方法一属于先按份数法算出增量、再根据增速误差对增量进行修正；事前修正则在运算前先调整乘数（现期量）。
- 如果份数法采用的增长率比真实值**估大**，得到的增量也偏大，可尝试预先将现期量适当**调小**以补偿；当修正后的现期能凑整、使计算更方便时，优先事前修正。
- 如果调整后的现期没有变得更好算，就不必强求事前修正，仍按份数法先算增量后修正。
- 此处的「现期×增长率」是对近似乘式的口头描述，**不能替代**份数法中「现期×增长量占现期比例」（例如正增长 r≈1/n 时现期/(n+1)）的具体估算式。用户未给出新题目数值，不自行编造例题或修正比例。此前15%近似为14.3%属于**估小**而非估大，不能套用「调小现期」的方向。

## 第4课「份数思想 → 份数法修正」（2026-11-12）

沿用 `data-topic-course-04-estimation.contentSections[1]` 的「份数思想」，在其中新增「份数法修正」方法卡（`items[].subitems`），下设两种修正方法。注意不要在「化除为乘」下另起章节，也不要把两种方法展开成同级流水账。

- **共同场景**：真实增长率15%，份数法近似为14.3%（约1/7），增长率低估**0.7个百分点**。
- **方法一：增量与增长率近似同比**。同现期下，Δ₁/Δ₂=(1+r₂)/(1+r₁)×r₁/r₂≈r₁/r₂。因为两个增长率接近，两个(1+r)也接近。按这种近似，估算增长量要按15/14.3的比例修正，约增加4.9%；**不能把增长率差0.7个百分点误写成增长量直接加0.7%**。
- **方法二：事后修正**。先按1/7得到增量≈现期/8；再用现期−增量估算基期；最后用估算基期×(15%−14.3%)补回少算的增长量，再与原估算增量相加。原有两种计算步骤必须保留，补算是近似值。
- 页面新增对可选 `subitems` 的支持，使“份数法修正”下两种方法具有真实标题层级；全文检索也包含子方法。数学公式按需渲染。此次仅补知识，无新的原题或图片。


简单单序列统计图可以通过数字渲染 SVG；复杂组合图、双坐标轴、堆积/多系列若无法可靠结构化应使用经过压缩的原图，不得为迁就渲染器擅自修改统计数据。

## 第3课放缩运算：统一教学口径（2026-11-10）

用户提供第3课讲义第21—29页与“百化分”表，已更新正式知识点 `data-topic-course-03-scaling`：

- 加法：有借有还，误差相互抵消；平均数用削峰填谷/偏差法。
- 减法：同加同减保持原差，近似调节时监控两侧调整量差。
- 除法是速算重点：先使分母凑成易算分数，再根据分母调整量按原商补偿分子，最后核对选项精度。尤其要重视窄选项间距和高精度题。
- 常用“百化分”由该 topic 的 `contentSections` 中“除法放缩→百化分”的 `table` 保存并真实渲染为表格，格式：`[{title,headers:[...],rows:[[...]],note}]`，数学单元格支持 LaTeX。
- 特殊规律：0.aaa（a为1—9的同一数字）≈a/9，除以该分数变成乘9/a，先除以a再错位乘10减自身；0.09粗略近似1/11，除以该分数相当于乘11，即错位乘10加自身。特别警惕0.09≠1/11，约有1%误差，不得用于未经核对的高精度题。
- 不要在其他资料分析课程中机械套用这些近似，始终以材料数值、误差传递和选项距离判断是否适用。

**未来每次辅导资料分析速算，优先按“识别对象→选择放缩→调整/补偿→核对误差→决定答案”的顺序解释**。不自动把用户讨论题录入题库，除非用户明确要求更新/入库。
