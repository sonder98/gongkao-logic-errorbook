# 资料分析模块：数据结构与增量入库说明

资料分析是第三个学习模块，与论证逻辑、形式逻辑平行；已开始正式录题，当前有1份文字材料和1道练习题。**不要把文档里的格式示例当作真题入库。**

## 课程知识体系

知识目录以用户的实际课程安排为主线，不再先验地按“增长、比重、平均数”等通用公式分类。当前目录节点如下：

| 目录分组 | 课程节点 |
|---|---|
| **速算** | 第2课 数据分析；第3课 放缩运算；第4课 快速估算 |
| **增长率计算** | 第5课 增速的累积与拆分；第6课 拉平增长率 |
| **分式与比重** | 第7课 分式混合；第8课 分式比较大小；第9课 比重特殊问题 |
| **年均与贡献** | 第10课 年均变化；第11课 增长贡献率与拉动增长率 |
| **其他题型** | 第12课 容斥问题；第13课 假设代入 |

目前仅建立课程目录节点，**不代表已经掌握或录入了视频中的完整方法**。每个节点的公式、使用条件、速算步骤和易错点，应在用户实际学习并核对课程内容后再补充；不从课程标题臆测解题规则。

## 文件职责

- data-materials.json：共用材料，一篇材料对应多题，由 blocks 构成。
- data-questions.json：每个题目通过 materialId 关联材料，题目 ID 使用 data- 前缀，跨所有题库唯一。
- data-knowledge.json：知识章节/方法。每个知识点 questionIds 引用真实题目 ID；知识 ID 使用 data-topic- 前缀。
- data-analysis.js：前端结构化渲染、校验和数学公式加载（KaTeX），独立于原 Supabase 代码。
- data-analysis.css：双栏材料与题目、响应式表格和图表样式。
- assets/data-analysis/：仅用于确实需要保存的材料图片，优先压缩 WebP，不放 Base64。
- tests/validate-data-analysis.cjs：数据校验和渲染夹具测试，不需要网络。

## 材料结构（以下为格式示例，非入库真题）

~~~json
[
  {
    "id": "data-material-2026-example",
    "title": "某地区产业统计",
    "year": "2026",
    "exam": "未知",
    "blocks": [
      {"type": "paragraph", "text": "下表为某地统计数据。"},
      {"type": "table", "columns": ["年份", "产值（亿元）"], "rows": [["2024", "120"], ["2025", "150"]], "caption": "单位：亿元"},
      {"type": "chart", "chartType": "bar", "data": [{"label": "2024", "value": 120}, {"label": "2025", "value": 150}]},
      {"type": "image", "src": "assets/data-analysis/chart.webp", "alt": "原始统计图", "caption": "仅在无法可靠结构化时使用"}
    ]
  }
]
~~~

blocks 支持：paragraph、table、chart（bar / line 单序列）、image。一份材料可以混合多类 blocks，按原文顺序呈现。table 单元格可以是字符串，或 { "text": "...", "colspan": 2, "rowspan": 1 } 对象。图片只允许引用 assets/data-analysis/ 下的 .webp、.png、.jpg、.jpeg，不支持远程 URL、Data URI 和 Base64。

简单单序列统计图可以通过数字渲染 SVG；复杂组合图、双坐标轴、堆积/多系列若无法可靠结构化应使用经过压缩的原图，不得为迁就渲染器擅自修改统计数据。

## 题目结构（格式示例，非入库真题）

~~~json
[
  {
    "id": "data-2026-example-q1",
    "materialId": "data-material-2026-example",
    "year": "2026",
    "exam": "未知",
    "title": "某地区产业产值增长率",
    "category": "增长率",
    "type": "计算题",
    "difficulty": "易",
    "stem": "根据材料计算相关指标。",
    "ask": "2025 年同比增长率为多少？",
    "options": ["10%", "15%", "20%", "25%"],
    "answer": "D",
    "analysis": {
      "identify": "增长率",
      "locate": "2024 年为 120，2025 年为 150",
      "formula": "\\[\\frac{150-120}{120}=25\\%\\]",
      "quick": "差值 30 除以基期 120",
      "trap": "不能用现期 150 作分母"
    },
    "rule": "增长率分母取基期",
    "important": false
  }

~~~

年份、题干、选项、来源和答案只依据真实题目或人工核对的信息；无法确认填“未知”，不能编造。新题不上传整页截图，需要图片时仅保存单独的图形材料。

## 2017江苏邻里调查：乘法放缩（2026-11-11）

- 材料 ID `data-material-2016-neighbor-relationship-survey`（2016年调查），题目 ID `data-2017-jiangsu-neighbors-unaware-count`（2017江苏）；答案 D，关联第3课「放缩运算」。
- 题目来自用户截图，原文按文字存储，**不上传原始截图**。
- 用户指定列式 `(951-6)×44.2%=945×44.2%`，只保留其两种计算方法：
  1. 44.2%≈44.4%≈4/9，945除9得105，105×4=420；44.2到44.4约相差0.5%，结果回减约0.5%，得418。
  2. 945≈940，44.2%≈44%=40%+4%，940×40%=376，940×4%=37.6，合计413.6；两边都向下近似，**累计**使结果约低1%，因此补约4，417.6≈418，D。
- 用户口述「错位相加小了1%」需在网页解释为**两个乘数一并向下近似造成的合计偏差**，不是错位相加这一运算本身带来1%的误差。此处仅调整误差描述的准确性，不增加第三种解法。
- 课程知识点新增「乘法两边反方向小幅等比例调整」，理论 `A(1+r)B(1-r)=AB(1-r²)`，例 `8622×2.1%≈9000×2%=180`；本题两边同向缩小属于近似计算后再补偿，不应误称反向平衡。

## 第4课「快速估算」之化除为乘（2026-11-11）

这是实际学习确认的知识，关联稳定知识点 `data-topic-course-04-estimation`，不新增第4课并列章节。

- **适用**：增长率绝对值10%以内。正增长先用现期×r粗估增长量（偏大约r），选项密集时再用`现期×r－现期×r×r`修正；负增长的减少量先估`现期×|r|`时偏小，可适当向上修正。
- **修正顺序**：优先检查「现期」或「增长率」哪边按误差率修正后更容易乘；方便就提前修正，不方便就先算结果再修正。不要叠加重复修正。
- **速判正增长率**：3.1%的整数部分平方9、小数对应10，10－9＝1，所以修正可取3%；7.5%的整数部分平方49、小数对应50，50－49＝1，所以近似修到7%。
- **负增长率例子**：7.4%的整数部分平方49，小数对应40，49＋40＝89，接近100，所以修正后有效比率略低于8%；同时把965.9调到960作轻微补偿。
- **增速速查表**：存储在第4课 topic 的 `tables` 字段，含正负各7组修正前后数值；表格原生排版，不上传截图。
- **课堂示例**：413×4.2%提前把4.2%修为约4%，直接算413×4%=16.52。
- **2015河北正式题**：`data-2015-hebei-2013-highway-passengers`，材料`data-material-2014-national-passenger-transport`。先算190.5×2.8%≈5.33，因选项B、C仅差0.15，再修正到5.18，基期185.32，选C。
- **2020福建正式题**：`data-2020-fujian-2018-industrial-profits`，材料`data-material-2019-fujian-industrial-profits`。原始乘式965.9×7.4%；若现期修大则超过1000不方便，选择修正增长率到8%，再把965.9调小到960；960×8%=76.8，再加966得1042.8≈1043，选C。用户原口述“966＋76.8＝1044”为心算量级表达，实际加法为1042.8，题库已按正确加法展示且不改变选项。
- 内容严格遵循用户的讲课和题目计算顺序；不自行补写其他解法；原题均使用结构化文字，不上传截图。

## 第4课快速估算：份数思想（2026-11-12）

用户提供课程讲义两张图片：份数思想主要用于增长率绝对值大于10%的快速粗略估算。当前讲义公式与表格给出**正增长**时的关系，按原文保存，不自行补充负增长的换算。

- 核心：当 \(r≈1/n\) 时，增长量 \(Δ≈现期/(n+1)\)。
- 份数理解：基期为n份，增加1份后现期n+1份，故增长量占现期的1/(n+1)。
- 常用表已写入 `data-topic-course-04-estimation.tables[1]`：一侧50%、33.3%、25%、20%、16.7%、14.3%；另一侧12.5%、11.1%、aa.a%、28.6%、40%、66.7%，各项分别记录“对应分数→增量占现期比例”，原生表格和数学公式渲染，不储存讲义截图。
- 表中`aa.a%` 对应 \(a/9\) 和 \(a/(9+a)\)，a为相同数字（例如22.2%对应2/9）。
- 仅更新已有第4课知识点，不增加虚构例题，不修改任何已有题目和材料，也不触碰用户的云端进度。

## 公式语法

在 analysis.*、知识点 summary / patterns 等文本字段支持行内公式 \(\frac{A}{B}\)，独立公式 \[\frac{A-B}{B}\]，也支持 aligned 环境多行计算。在 JSON 中反斜杠必须正确转义（例如源文本内写两个反斜杠代表一个 LaTeX 反斜杠）；请先校验 JSON。公式引擎按需从固定版本 KaTeX CDN 加载，失败时显示原始 LaTeX 文本，不阻断答题。

## 第3课放缩运算：统一教学口径（2026-11-10）

用户提供第3课讲义第21—29页与“百化分”表，已更新正式知识点 `data-topic-course-03-scaling`：

- 加法：有借有还，误差相互抵消；平均数用削峰填谷/偏差法。
- 减法：同加同减保持原差，近似调节时监控两侧调整量差。
- 除法是速算重点：先使分母凑成易算分数，再根据分母调整量按原商补偿分子，最后核对选项精度。尤其要重视窄选项间距和高精度题。
- 常用“百化分”由该 topic 的 `tables` 保存并真实渲染为表格，格式：`[{title,headers:[...],rows:[[...]],note}]`，数学单元格支持 LaTeX。
- 特殊规律：0.aaa（a为1—9的同一数字）≈a/9，除以该分数变成乘9/a，先除以a再错位乘10减自身；0.09粗略近似1/11，除以该分数相当于乘11，即错位乘10加自身。特别警惕0.09≠1/11，约有1%误差，不得用于未经核对的高精度题。
- 不要在其他资料分析课程中机械套用这些近似，始终以材料数值、误差传递和选项距离判断是否适用。

**未来每次辅导资料分析速算，优先按“识别对象→选择放缩→调整/补偿→核对误差→决定答案”的顺序解释**。不自动把用户讨论题录入题库，除非用户明确要求更新/入库。
